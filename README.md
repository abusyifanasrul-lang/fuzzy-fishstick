# Pocket Platformer

A tiny 2D platformer that runs in a mobile browser, ideal for Android phones.

## Run

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000` on your Android device (same network).

## Controls

- Tap and hold ◀ ▶ to move.
- Tap ⬆ to jump.
- Collect the stars to boost your jump, then grab the flag.
